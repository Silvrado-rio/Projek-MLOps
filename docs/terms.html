Ketentuan Penggunaan — Project-MLOps DVC

Diperbarui: 9 Oktober 2026.

Aplikasi digunakan oleh pemilik akun untuk proyek pembelajaran mengenai pipeline dan versioning dataset. Pengguna bertanggung jawab atas akses akun, kuota Google Drive, pengaturan berbagi, serta kredensial yang dipakai workflow.

Sumber metadata adalah MangaDex dan harus dicantumkan saat data digunakan. Penggunaan API dan metadata tetap mengikuti ketentuan sumber serta layanan Google dan GitHub yang digunakan. Proyek tidak memberikan hak atas gambar atau isi karya.

Data dapat berubah atau tidak tersedia. Kelengkapan riwayat, hasil prediksi, dan ketersediaan layanan tidak dijamin. Sampel yang dikumpulkan tidak dianggap mewakili seluruh manhwa.

Pengguna dapat menghentikan penggunaan dengan menonaktifkan workflow dan mencabut akses OAuth. Penanganan data dijelaskan pada kebijakan privasi.
