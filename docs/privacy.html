Kebijakan Privasi — Project-MLOps DVC

Diperbarui: 9 Oktober 2026.

Akses dan penggunaan data

Aplikasi pribadi ini menggunakan OAuth Google untuk mengizinkan DVC membaca dan menulis cache dataset pada folder Google Drive yang ditentukan pengguna. Backend DVC meminta scope Google Drive dan appdata; scope Drive memberikan izin yang luas, meskipun workflow proyek diarahkan ke folder remote dataset. Workflow tidak ditujukan untuk mengolah dokumen pribadi lain milik pengguna.

Data proyek berasal dari metadata publik MangaDex, termasuk identitas karya, statistik komunitas, dan metadata chapter. Aplikasi tidak mengambil gambar atau isi chapter.

Penyimpanan dan pembagian

Cache dataset disimpan di Google Drive pengguna. Kredensial OAuth lokal disimpan di luar file yang dilacak Git. Untuk otomatisasi, kredensial disimpan sebagai GitHub Actions Secrets dan dipakai oleh runner workflow. Pointer DVC dan kode disimpan di Git; hasil run dapat tersedia sebagai artifact GitHub selama 14 hari dan mengikuti akses repository. Folder Drive tetap mengikuti pengaturan berbagi yang ditetapkan pemilik.

Proyek tidak menjual data Google pengguna, tidak menggunakannya untuk iklan, dan tidak menggunakan data pribadi Google untuk melatih model. Google Drive dan GitHub digunakan untuk penyimpanan dan eksekusi proyek. Penggunaan informasi dari API Google mengikuti Google API Services User Data Policy, termasuk persyaratan Limited Use.

Kontrol pengguna

Pengguna dapat menghentikan workflow, menghapus secrets, mencabut izin aplikasi melalui pengaturan akun Google, dan menghapus cache dari folder Drive. Pencabutan izin menghentikan akses berikutnya, tetapi tidak otomatis menghapus data yang sudah disimpan. Penghapusan cache dapat membuat versi dataset terkait tidak dapat dipulihkan.

Pertanyaan proyek dapat disampaikan kepada pengelola melalui halaman Issues repository. Jangan menyertakan token atau kredensial.
