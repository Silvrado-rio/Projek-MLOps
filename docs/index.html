Project-MLOps DVC

Aplikasi pribadi untuk mencatat versi dataset metadata manhwa MangaDex dengan DVC. Pengambilan data berjalan melalui GitHub Actions. Google Drive milik pengguna menjadi tempat penyimpanan cache dataset yang dapat dipulihkan kembali.

Dataset berisi metadata katalog, statistik komunitas, dan metadata chapter. Aplikasi tidak menyimpan gambar atau isi chapter. Akses Google Drive digunakan untuk membaca dan menulis cache DVC pada folder remote yang dikonfigurasi pemilik akun.

Aplikasi ini digunakan untuk proyek pembelajaran oleh pemilik akun dan tidak menawarkan layanan login kepada masyarakat umum.
